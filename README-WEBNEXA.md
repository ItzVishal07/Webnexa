# WebNexa — GitHub Pages package (no Supabase)

Upload these files directly to the ROOT of the `Webnexa` repository. This package is intentionally flat to match the current repository layout: `style.css`, `site.js`, `webnexa-logo.svg`, `favicon.svg`, and `vishal-kocherla.jpeg` are beside the HTML pages.

Pages: `index.html`, `services.html`, `work.html`, `about.html`, `contact.html`.

No Supabase, database, backend, build step, or paid service is required. Contact form uses email (`mailto:admin.webnexa@gmail.com`) rather than a database.

After upload, enable GitHub Pages in Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
