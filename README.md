# WebNexa — SAMYAK-inspired full website

This is a full static website for GitHub Pages with an energetic, event-inspired visual style adapted for WebNexa (not a copy of SAMYAK branding/content).

## Files
- `index.html` — redesigned homepage with hero, service highlights, impact strip, featured concepts, process, founder intro and CTA
- `services.html`, `work.html`, `about.html`, `contact.html` — separate pages
- `css/style.css` — responsive shared styling
- `js/site.js` — mobile navigation, reveal animations and counters
- `assets/webnexa-logo.svg`, `assets/favicon.svg`, `assets/vishal-kocherla.jpeg` (founder portrait on About page)
- `robots.txt`, `sitemap.xml`, `.nojekyll`

## Publish
1. Back up your current GitHub repository.
2. Extract this ZIP.
3. Upload the CONTENTS of `WebNexa-Complete-SAMYAK-Style` into the repository root (do not upload the enclosing folder).
4. Replace matching HTML files and add/replace `css`, `js`, and `assets`.
5. Keep existing Supabase admin/CMS files unless you intentionally replace them later.
6. Commit changes, wait for GitHub Pages to publish, then open https://itzvish07.github.io/Webnexa/

## Before launch
- Contact email in `contact.html` currently uses admin.webnexa@gmail.com.
- Portfolio tiles are explicitly concept examples; replace with real projects before presenting them as completed work.
- Impact figures describe capabilities/process, not customer or project counts.
- Static pages are not yet connected to Supabase CMS.
